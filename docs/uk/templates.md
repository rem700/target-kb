## Юніт-економіка
| Показник | Значення | Як рахувати |
|---|---|---|
| Середній чек | | виручка / кількість замовлень |
| Собівартість замовлення | | товар + пакування + доставка + комісії |
| Прибуток із замовлення | | чек − собівартість |
| Частка прибутку на рекламу | | зазвичай 30–60% |
| **Допустима ціна покупця** | | прибуток × частка |
| Конверсія заявки в продаж | | продажі / заявки (для послуг) |
| **Допустима ціна заявки** | | ціна покупця × конверсія |
| Мінімальний денний бюджет | | ціна результату × 50 / 7 |

## Чек-лист перед запуском
- [ ] Ціль кампанії збігається з тим, що справді потрібно бізнесу
- [ ] Піксель і CAPI працюють, подія оптимізації спрацьовує
- [ ] UTM-мітки в оголошеннях
- [ ] Розширення локації вимкнено (якщо важлива географія)
- [ ] Витрати на виключені місця показу вимкнено (якщо щось виключали)
- [ ] Креативні покращення перевірено
- [ ] 3–6 різних концептів у форматах 9:16 і 4:5
- [ ] Тексти перевірено на обмеження (особисті характеристики, обіцянки)
- [ ] Посадкова сторінка швидко відкривається з телефона, ціну видно одразу
- [ ] Посилання, форми, телефон, месенджер перевірено вручну
- [ ] Ліміт витрат на акаунт встановлено
- [ ] У календарі нагадування: не чіпати 3–7 днів
