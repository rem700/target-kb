# Шаблоны

Готовые заготовки: копируйте в заметки, Google Таблицы или Notion и заполняйте.

## Юнит-экономика
| Показатель | Значение | Как считать |
|---|---|---|
| Средний чек | | выручка / число заказов |
| Себестоимость заказа | | товар + упаковка + доставка + комиссии |
| Прибыль с заказа | | чек − себестоимость |
| Доля прибыли на рекламу | | обычно 30–60% |
| **Допустимая цена покупателя** | | прибыль × доля |
| Конверсия заявки в продажу | | продажи / заявки (для услуг) |
| **Допустимая цена заявки** | | цена покупателя × конверсия |
| Минимальный дневной бюджет | | цена результата × 50 / 7 |

## Бриф на креатив
```
Название концепта:
Для кого (персона):
Зачем покупать (мотивация):
Главная мысль одной фразой:
Хук (первые 3 секунды):
Доказательство (отзыв / процесс / цифра):
Призыв к действию:
Формат: видео 9:16 / карусель / фото 4:5
Длина:
Кто в кадре:
Музыка (из лицензионной библиотеки):
Чем отличается от уже запущенных концептов:
```

## Еженедельный отчёт
```
Неделя: __.__ – __.__

Потрачено:              € (план: €)
Результатов (кабинет):
Результатов (CRM/магазин):
Цена результата:        € (цель: €)
Выручка:                €
ROAS:

Лучший креатив:              почему:
Худший креатив (выключен):   почему:
Частота:                     (растёт? значит, скоро выгорание)

Что изменили на этой неделе:
Что пробуем на следующей:
Вопросы / проблемы:
```

## Чек-лист перед запуском
- [ ] Цель кампании совпадает с тем, что реально нужно бизнесу
- [ ] Пиксель и CAPI работают, событие оптимизации срабатывает
- [ ] UTM-метки в объявлениях
- [ ] Расширение локации выключено (если важна география)
- [ ] Траты на исключённые места показа выключены (если что-то исключали)
- [ ] Креативные улучшения проверены
- [ ] 3–6 разных концептов в форматах 9:16 и 4:5
- [ ] Тексты проверены на ограничения (личные характеристики, обещания)
- [ ] Посадочная страница открывается быстро с телефона, цена видна сразу
- [ ] Ссылки, формы, телефон, мессенджер проверены руками
- [ ] Лимит расходов на аккаунт установлен
- [ ] В календаре напоминание: не трогать 3–7 дней
