## Unit economics
| Metric | Value | How to calculate |
|---|---|---|
| Average order value | | revenue / number of orders |
| Cost per order | | product + packaging + delivery + fees |
| Profit per order | | order value − cost |
| Share of profit for ads | | usually 30–60% |
| **Max cost per customer** | | profit × share |
| Lead-to-sale rate | | sales / leads (for services) |
| **Max cost per lead** | | cost per customer × rate |
| Minimum daily budget | | cost per result × 50 / 7 |

## Pre-launch checklist
- [ ] Campaign objective matches what the business really needs
- [ ] Pixel and CAPI work, the optimization event fires
- [ ] UTM parameters in the ads
- [ ] Location expansion off (if geography matters)
- [ ] Spend on excluded placements off (if you excluded anything)
- [ ] Creative enhancements reviewed
- [ ] 3–6 different concepts in 9:16 and 4:5
- [ ] Copy checked against restrictions (personal attributes, promises)
- [ ] Landing page loads fast on a phone, price visible right away
- [ ] Links, forms, phone, messenger checked by hand
- [ ] Account spending limit set
- [ ] Calendar reminder: don't touch for 3–7 days
